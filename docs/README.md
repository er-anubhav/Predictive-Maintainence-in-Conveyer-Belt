# Project Documentation Module

## Future Purpose
The `docs/` module contains architectural diagrams, hardware schematics, pinout tables, deployment manuals, and SIH submission artifacts.

Planned documentation:
- **System Architecture**: High-level block diagrams depicting sensor nodes, edge gateways, cloud/on-premise backend, and user applications.
- **Hardware Specifications**: Bill of Materials (BOM), sensor ratings for mining environments (IP67/68, ATEX/dust proofing), and schematic files.
- **API Reference**: OpenAPI specifications, payload schemas, and integration documentation for mine SCADA systems.
- **Maintenance Protocols**: Field procedures for sensor node calibration and conveyor joint inspection.

*Note: In Milestone 1, please refer to the root `README.md` for core setup, architecture, and running instructions.*
